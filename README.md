# Classic Computer Vision

Лабораторные работы по компьютерному зрению (ВМК МГУ).  
Каждая папка — отдельный проект с кодом, заданием и отчетом.

---

## 📂 Структура репозитория

- [image_segmentation/](image_segmentation/)  
  Сегментация и классификация объектов на изображениях:
  1. **main.py** — GUI-приложение на Tkinter для загрузки изображений и сегментации с помощью FastSAM + OpenCV.
  2. **report.pdf** — отчет с описанием алгоритма, теорией и примерами результатов.

- *task_2/* (будет добавлена позже)  
  Вторая лабораторная работа.

---

## 🛠️ Технологии

- **Язык**: Python 3
- **Библиотеки**:
  - OpenCV — обработка изображений, морфология, цветовые пространства
  - NumPy — работа с массивами пикселей
  - FastSAM (Ultralytics) — нейросетевая сегментация
  - Matplotlib — визуализация результатов
  - Tkinter — графический интерфейс

---

## Установка и запуск

```bash
pip install -r requirements.txt
cd image_segmentation
python main.py
```

При первом запуске автоматически скачается модель FastSAM-x.pt.
